# Vocab 1528 — Range Mission

`テキスト(2).txt` の1528項目を使った、GitHub Pages / iPhone / iPad対応のPWA英単語学習サイトです。

## 学習ルール

- 意味は **括弧の外側にある「，」または「,」だけ**で分割します。
- `(卵を)産む`、`交通(量)`、`(もし～なら)できる` のように、括弧内の文字は分割しません。
- 全1528項目から **2187個の意味単位**が生成されます。
- 1意味につき3回正解でクリア。全範囲なら **6561有効正解**でクリアです。
- 同じ英単語の別意味は、同じ4択候補には出しません。
- 不正解でも正解回数は減らさず、4〜6問ほど後に再出題します。
- 誤答の多い意味は、通常の出題で少し優先されます。

## 範囲・ノルマ

- 開始番号と終了番号を自由指定できます。
- 100項目ごとのプリセットもあります。
- 選択範囲内の意味数・総必要正解数・残り正解数を自動計算します。
- 目標日を設定すると、必要な1日ノルマ（有効正解/日）を自動計算できます。
- 範囲を変更しても、各意味の学習進捗は保持されます。

## 見た目

サイトを開くたびに差し色がランダムに変わります。右上の色の丸を押すと、その場でも別の差し色へ変更できます。

## GitHub Pages

このフォルダの中身をリポジトリ直下へアップロードし、GitHub の `Settings` → `Pages` → `Deploy from a branch` → `main / root` を選択してください。

`.nojekyll` はそのまま置いて構いません。

## 保存

進捗・範囲・目標日・ノルマは `localStorage` に保存されます。データは外部サーバーへ送信しません。JSONで書き出し／読み込みもできます。
