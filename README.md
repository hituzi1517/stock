# Vocab 1528+ — テスト前「1周1回のみ」修正版 v6

以前のVocab 1528+をそのまま引き継ぎ、テスト前タブの周回処理を再構築したiPhone / GitHub Pages用PWAです。

## テスト前のルール（v6）

1. 範囲でNo.301〜500を指定したら、1周目は重複のない200単語の200問です。
2. **正誤に関係なく**1問答えるとその周の回答数が1増えます。不正解になっても同じ周には出ません。
3. 200問目に回答した瞬間に「1周目 200/200」が表示されます。「1周目終了 → 2周目へ」を押すと2周目は1周目の不正解だけになります。
4. 2周目・3周目も同じルールです。各周の不正解だけが次の周へ残り、1回でも正解した単語はテスト完了となります。
5. 複数意味は出題のたびに再抽選。第1意味を70%、その他を合計30%（均等割り）で選択。
6. テスト側の正誤/周回記録は通常の3回正解進捗と独立。途中保存・再開・履歴・バックアップに対応。

## v6の再発防止

- 周の開始時に重複のない出題順（`roundOrder`）を保存します。
- 出題を進める位置（`roundIndex`）と回答済み番号（`roundAnsweredIds`）を別途保存します。
- 不正解は次の周へのリスト（`roundMissed`）に記録する**だけ**で、現在の出題順へ戻しません。
- 途中でアプリを終了しても、未回答の1問はそのまま復元。回答済みの問題を二重計上しません。
- 各周の結果（正解数/不正解数/誤答した番号）を終了時に固定して履歴へ追加します。2周目に正解しても1周目の誤答は書き換わりません。

## 既存の進捗・古いテスト

- 通常学習の保存キーは変更していません。従来の進捗はそのままです。
- v5テストは現在の周の回答済み回数・未回答問題・誤答を保持してv6へ移行します。
- v3/v4テストは「どの単語を1周目で一度答えたか」を保存していなかったため、残りの未クリア単語から新方式の周回を作ります。過去の正解/不正解総数は保持しますが、過去の周を厳密には復元できません。
- 正確な「200問の1周目」を実施する場合はv6で新しいテストを作ってください。過去のテストは履歴へ残ります。

## iPhoneへの反映・確認

ZIP内の `vocab-1528-plus-pwa` フォルダの**中身**をGitHub Pagesのリポジトリ直下に上書きしてください。PWAのキャッシュは `vocab1528-plus-v6-once-per-round` に更新、JS/CSSのURLにもv6の識別子を付けています。

サイトの「テスト前」タブ上部に `EXAM PREP · v6 NO REPEATS` と出ていることを確認してください。表示がv5など旧版のままならiPhoneのPWAのキャッシュがまだ古い可能性があります。オンラインで一度Safariからサイトを開き直し、PWAを終了→起動して確認してください。**データをバックアップする前にホーム画面アプリを削除しないでください。**

元の1528単語と意味の表記は変更していません。
