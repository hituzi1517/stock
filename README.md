# Vocab 1528+ — テスト前・周回式復習 v5

旧 Vocab 1528+ の通常学習と保存キーを維持した、iPhone / iPad / GitHub Pages 用PWAです。

## テスト前：周回式の復習（通常学習と独立）

- No.301〜500を指定したら、**1周目は200単語＝200問**。問題数指定欄はありません。
- 1周目は200単語をランダム順に**各1回だけ**出題します。
- **正解した単語はそのテストでクリア**し、不正解だけ2周目の対象になります。例：200→35→8→0（全問クリア）。
- 不正解は同じ周には再登場しません。2周目・3周目の順番も毎回ランダムです。
- **問題を表示するたびに意味を再抽選**。第1の意味が70%、第2以降の意味の合計が30%（均等配分）。したがって間違えた単語が次の周で別の意味になる場合があります。
- テスト専用の英→日 / 日→英 / ごちゃまぜに対応。解答後は4択すべての解説が表示されます。英語読み上げ付き。
- 周回番号、周内回答数、累計クリア数、正答率、周回履歴を表示。途中の問題と出題待ちキューを保存するため、閉じても再開できます。
- テストのデータは `vocab1528-testprep-v1` に保存。通常学習の正解数・回数は変わりません。JSONバックアップにもテスト履歴が含まれます。
- v3/v4で作成済みの進行中テストは、**クリア済み単語と累計正誤を保持**して新方式に移行します。未クリアの単語を新しい周のキューに並べ直すため、移行直後の周回カウントは1周目からです。過去のテスト履歴は残ります。
